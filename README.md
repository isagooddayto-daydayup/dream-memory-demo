# 回忆与梦境 · dream2 手机版 (mobile web prototype)
Touch: left joystick = move (push to edge = run) · drag right side = look · buttons: 跳 jump, 上升/下降 fly up/down, 飞行 fly toggle, 溶解T dissolve, 镜头C camera, 第一人称 V, 角色 character, 场景 scene menu.
Desktop keys also work (WASD, mouse, Space, Q, F, C, V, T, P, G, M, 1-3, J jump).
Scenes: 1 Fujian mining town (Marble, 650k splats), 2 mining-area school (Marble, 500k), 3 ARES Mars base (mesh). Built with three.js + Spark (MIT).
Asset licences: see SOURCES.md — several character models have UNVERIFIED licences.
